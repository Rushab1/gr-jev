\section{Terms and measures}
\label{app:terms}
\begin{itemize}
\item Option: one entry of the list sent with a query (a tool, a choice, a passage, an article, a team).
\item Correct option: an option that the dataset labels as correct for the query. Distractor: any other option.
\item Prediction: the option in the \texttt{choice} field of the answer.
\item Confidence: the highest probability of an answer.
\item Accuracy: the share of answers whose prediction is a correct option.
\item Refused list: a list for which the model returns an answer of type \texttt{refusal} and no probabilities.
\end{itemize}

\section{Lists and instructions}
\label{app:lists}
\begin{itemize}
\item A list of identical options or of random options is sent in each of its cyclic permutations, so every option is at every position once.
\item The MetaTool lists with one correct tool end with the option ``None'', as in the dataset.
\item MetaTool repeats queries across its test files. An answer to a repeated request is counted once per example.
\end{itemize}

\section{Refusals of GPT-6 Luna Decisions}
\label{app:refusals}
\begin{itemize}
\item 24,286 of 202,088 questions refused (12.0\%).
\item By kind of list: 18,639 of 26,460 lists of random options; 3,458 of 17,231 lists made of the example's distractors; 1,545 of 39,530 lists with only correct options; 526 of the 103,912 other lists; 118 of 14,955 yes/no questions.
\item A refusal has no probabilities and no reason.
\item One refused request was sent again seven times, with one change each time. The model answered the same passages when the query was changed to one that a passage fits. It answered the same query when a ``none of the above'' option or a fitting passage was added.
\end{itemize}

\section{Support tickets}
\label{app:tickets}
\begin{itemize}
\item Teams and descriptions, from TypeSafe's example: returns (``Exchanges, wrong or damaged items''), shipping (``Delivery status, delays, lost packages''), billing (``Charges, invoices, payment problems''). Instruction: ``Which team should handle this?''
\item Claude Opus 5.5 wrote 24 problems, eight per team, on 11 October 2026.
\item 12 pairs of problems for two different teams, each pair sent in both orders: 24 tickets.
\item Every problem and pair is in \texttt{src/grjev/stimuli/tickets.json}.
\end{itemize}
