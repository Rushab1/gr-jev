\section{Terms and measures}
\label{app:terms}
\begin{itemize}
\item Choice: one entry of the list sent with a query (a tool, a choice, a passage, an article, a team).
\item Correct choice: a choice that the dataset labels as correct for the query. Distractor: any other choice.
\item Prediction: the choice in the \texttt{choice} field of the answer.
\item Confidence: the highest probability of an answer.
\item Accuracy: the share of answers whose prediction is a correct choice.
\item Refused list: a list for which the model returns an answer of type \texttt{refusal} and no probabilities.
\end{itemize}
