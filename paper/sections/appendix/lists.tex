\section{Lists}
\label{app:lists}
\begin{itemize}
\item A list of identical choices or of random choices is sent in each of its cyclic permutations, so every choice is at every position once.
\item The MetaTool lists with one correct tool end with the choice ``None'', as in the dataset.
\item MetaTool repeats queries across its test files. An answer to a repeated request is counted once per example.
\end{itemize}
