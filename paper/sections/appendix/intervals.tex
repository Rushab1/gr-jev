\section{Confidence intervals}
\label{app:intervals}
% The table is written by scripts/paper/paper_intervals.py.
We compute 95\% bootstrap intervals using 2,000 resamples of the examples. A resample keeps every answer to an example together. We select the threshold with the highest exact set accuracy across all examples. We use that threshold to compute exact set accuracy in every resample.
