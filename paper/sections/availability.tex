\section{Code and data availability}
\label{app:availability}
The code at \url{https://github.com/Rushab1/gr-jev} builds every list, sends the requests, and computes every figure and table. The repository holds every instruction sent to the models, and it does not hold the saved model responses. The code is released under the MIT License, and this paper uses the version tagged \texttt{arxiv-v1}.
